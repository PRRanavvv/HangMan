🪢 Hangman 🪢

A simple console-based Hangman game written in pure Python.

## Description

This project is a classic implementation of the Hangman word guessing game. Players try to guess a hidden word one letter at a time before running out of attempts. With each incorrect guess, another part of the hangman is drawn.

## How to Play

1. Run the script: `python hangman.py`
2. The game will select a random word
3. Guess letters by typing them when prompted
4. Try to guess the word before the hangman is complete!

## Features

- Random word selection
- ASCII art representation of the hangman
- Simple user interface
- No external dependencies

## Requirements

- Python 3.x
